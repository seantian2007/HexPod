# HexPod Academy

An interactive, bilingual (English / 中文) course that follows this robot's build, from the first servo to a hexapod walking under gamepad control.
Each stage page has plain-language explanations, drag-to-explore widgets, photos and clips from our own build, and a practice list that ends in a reward (something moves).

```
learn/
├── site/                     # the website: static files, no build step except the Stage 3 notebook
│   ├── index.html            # landing page
│   ├── i18n.js               # landing page text
│   ├── hexview.js            # tiny 3D hexapod renderer (shared by pages and the notebook)
│   ├── assets/
│   │   ├── site.css          # shared styles (light + dark)
│   │   └── core.js           # shared runtime: top bar, stage strip, language switch, pager, clips, canvas helpers
│   ├── build/                # "Build the robot": parts, assembly, wiring, first power, messenger firmware
│   ├── stage0/ … stage6/     # one folder per stage: index.html + i18n.js (all text) + page.js (widgets)
│   │   └── stage3/notebook/  # generated by build.sh (not committed)
│   └── media/
│       ├── ours/             # photos, plots and clips from our build
│       ├── rk/               # images and clips from rookidroid/hexapod (GPL-3.0)
│       └── CREDITS.md
├── notebooks/
│   ├── stage3_ik.py          # practice notebook (marimo): exercises + checkers + rewards
│   └── stage3_ik_solved.py   # same notebook with the answers filled in
├── build.sh
└── README.md
```

## How to run

From the `code/` folder:

```bash
cd learn/site && python3 -m http.server 8000
```

Open <http://localhost:8000/>. The language switch is in the top-right corner of every page.

Every page works this way. Only the Stage 3 practice notebook needs building first (it runs Python inside the browser):

```bash
pip install marimo          # once
bash learn/build.sh         # builds the notebook into site/stage3/notebook, then serves the site
```

To work through the notebook locally instead (needed for the "run it on the real robot" part):

```bash
marimo edit learn/notebooks/stage3_ik.py
```

Stages 0–2 and 4–6 list their exercises and show "Practice notebook: coming soon".

## Adding a language

- Pages: in each `i18n.js`, copy the `en` block, give it a new key (for example `es`) and translate it. Shared words (navigation, buttons) are in `COMMON_I18N` in `assets/core.js`; add the language's name to `LANG_NAMES` there.
- Notebook: in the last cell of `stage3_ik.py`, copy the `"en"` block of `TEXT`, and add the option to the `lang` dropdown in the second cell.

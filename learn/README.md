# HexPod Academy: Stage 3 (IK) pilot

A first try at turning the HexPod learning path into an interactive, bilingual course.
One stage only (Stage 3, inverse kinematics), to see how it feels before doing the rest.

```
learn/
├── site/
│   ├── hexview.js            # tiny 3D hexapod renderer (shared)
│   └── stage3/
│       ├── index.html        # the lesson page (explanations + 2 drag widgets + dancing hexapod)
│       ├── i18n.js           # ALL page text, one block per language (en is default)
│       ├── page.js           # widgets + language switch
│       └── notebook/         # generated by build.sh (not committed)
├── notebooks/
│   ├── stage3_ik.py          # practice notebook (marimo): 4 exercises + checkers + rewards
│   └── stage3_ik_solved.py   # same notebook with the answers filled in (for previewing)
├── build.sh
└── README.md
```

## How to run

Everything below runs from the `code/` folder.

**1. Install marimo (once)**

```bash
pip install marimo
```

**2. Try the practice notebook as a learner** (fastest way to see the idea)

```bash
marimo edit learn/notebooks/stage3_ik.py
```

A browser tab opens. Fill in the four ✏️ cells; each checker turns green as you go. When all five checkpoints pass, the two rewards (leg drawing a shape, hexapod dance) unlock.
Want to see the rewards right away? Open the solved copy instead:

```bash
marimo edit learn/notebooks/stage3_ik_solved.py
```

The language dropdown is in the top-right corner of the notebook.
The "Run it on the real robot" section at the bottom only works this way (running locally), with the ESP32 plugged in. It uses `utils/link.py`, so the serial port name in `Link` must be right.

**3. See the whole website** (lesson page + notebook running inside the browser, no Python needed for the reader)

```bash
bash learn/build.sh
```

Then open <http://localhost:8000/stage3/>. The language switch is top-right. The "Open the practice notebook" button opens the in-browser version (first load takes a few seconds while Python downloads into the browser).

## Adding a language

- Page: in `site/stage3/i18n.js`, copy the `en` block, give it a new key (e.g. `es`), translate, and add the name to `LANG_NAMES`.
- Notebook: in the last cell of `stage3_ik.py`, copy the `"en"` block of `TEXT` the same way, and add the option to the `lang` dropdown in the second cell.
